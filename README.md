# Resume Analyzer

AI-powered Resume Analyzer project using **Python, Generative AI, and Streamlit**.

## About This Project

Resume Analyzer is a GenAI-based application designed to analyze resume content and provide useful insights to help understand and improve a candidate's resume.

The project will use Python for application development, Generative AI for resume analysis, and Streamlit for the user interface.
